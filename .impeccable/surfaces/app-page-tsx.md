# Dream Wall surfaces

Scope: `/` is an Experience for a room watching a projector; `/admin` is Operate for a facilitator. User-pinned Neptune space world; the multi-round CLI workshop defines success. This is a functional app screen, built directly in code using the already-confirmed direction.

## Direction contract

THESIS: Each anonymous CLI submission becomes a star in the same Neptune sky. The wall is the artifact, not a marketing landing page or submission form.

OWN-WORLD: Deep midnight blue, crisp ice-white Thai copy, electric blue controls, real NASA Neptune photography, fine orbital geometry, compact Manrope labels. Spacious sky, readable opaque message surfaces, no decorative console scaffolding.

STORY: Read the exact event theme, see the live round and dreams, watch a new arrival take focus, then join a rotating wall. Facilitators operate a clear list with hide/restore and a destructive reset confirmation.

FIRST VIEWPORT: Full-height sky. Compact identity and round/status across the top; a large two-line event title anchors the upper left, Neptune occupies the right sky. Actual dreams occupy the open foreground below, up to six at a time with a separate readable arrival focus. Count and fullscreen control anchor the bottom. Empty, loading and offline states preserve this composition. Mobile stacks the sky and messages without clipping.

FORM: User-pinned Neptune dream constellation takes precedence over generated alternatives; seed:30d838e4c61fbc2e. The signature interaction is a new dream's single celebratory arrival, with a bounded queue and an immediate reset boundary. Reduced motion removes entrances and animated orbits.
